# SellShop

Плагин скупщика для Minecraft-сервера (Paper 26.3). Игрок пишет `/sell`, выбирает раздел и продаёт предметы за игровую валюту через Vault.

- **ЛКМ** по предмету — продать один стак
- **Shift + ЛКМ** — продать всё, что есть в инвентаре
- Свой GUI: меню рисует сервер, клиентские моды не нужны

## Возможности

- Главное меню с разделами, внутри раздела предметы с пагинацией
- В описании предмета: цена за 1 шт., цена за стак, сколько у игрока есть, выручка за всё
- Оплата через Vault; если выдача денег не прошла, предметы возвращаются игроку
- Лог каждой продажи в файл `sales.log`
- Счётчик проданного (`stats.yml`): что и сколько продали
- Админы могут забирать предметы из счётчика командой
- Админы сами добавляют предметы, цены и разделы, в том числе командами в игре
- Задел под донатную валюту (выключена по умолчанию)

## Требования

| Что | Версия |
|---|---|
| Minecraft-сервер | Paper 26.3 |
| Java (запуск сервера и сборка) | 25 |
| [Vault](https://www.spigotmc.org/resources/vault.34315/) | должен поддерживать вашу версию сервера |
| Плагин экономики с поддержкой Vault | EssentialsX, CMI и т.п. |
| Maven (только для сборки) | 3.9+ |

Без плагина экономики плагин запустится, но продажа за Vault работать не будет, а в консоль выведется предупреждение.

## Как собрать jar из исходников (из zip)

### Вариант 1: на своём компьютере

1. Установите **JDK 25** и **Maven**. Проверьте, что работают команды `java -version` и `mvn -version`.
2. Распакуйте `SellShop-repo.zip` (или `SellShop-source.zip`) в любую папку.
3. Откройте терминал в папке `SellShop`, где лежит файл `pom.xml`.
4. Выполните:

   ```
   mvn package
   ```

5. Готовый файл появится в папке `target/` под именем `SellShop-1.0.0.jar`.
6. Положите jar в папку `plugins/` сервера и перезапустите сервер.

Для сборки нужен интернет: Maven скачивает Paper API и VaultAPI.

Если сборка падает с ошибкой про зависимость `paper-api`, откройте `pom.xml` и замените версию `26.3.build.230-stable` на актуальную со страницы https://jd.papermc.io/paper/26.3/.

### Вариант 2: через GitHub (без установки Java и Maven)

1. Создайте на GitHub пустой репозиторий.
2. Распакуйте `SellShop-repo.zip` и в папке `SellShop` выполните:

   ```
   git remote add origin https://github.com/<ваш-логин>/SellShop.git
   git push -u origin main
   ```

3. Откройте репозиторий → вкладка **Actions** → последний запуск **Build** → раздел **Artifacts** → скачайте `SellShop-jar`.
4. Чтобы jar лежал в **Releases**, создайте тег:

   ```
   git tag v1.0.0
   git push origin v1.0.0
   ```

Сборку описывает файл `.github/workflows/build.yml`.

## Установка

1. Убедитесь, что на сервере стоят Vault и плагин экономики.
2. Положите `SellShop-1.0.0.jar` в папку `plugins/`.
3. Запустите сервер: в `plugins/SellShop/` появятся `config.yml` и `shop.yml`.
4. Выдайте администраторам право `sellshop.admin`.

## Команды

### Для игроков

| Команда | Право | Описание |
|---|---|---|
| `/sell` | `sellshop.use` (по умолчанию у всех) | открыть скупщик |

### Для администраторов

Основная команда `/selladmin`, короткий вариант `/sa`. Право: `sellshop.admin` (по умолчанию у операторов).

| Команда | Описание |
|---|---|
| `/sa help` | список команд |
| `/sa add <раздел> <цена> [предмет]` | добавить предмет с ценой за 1 шт. Если предмет не указан, берётся предмет из руки |
| `/sa price <раздел> <предмет> <цена>` | изменить цену предмета |
| `/sa remove <раздел> <предмет>` | убрать предмет из раздела |
| `/sa addcategory <id> <иконка> [название]` | создать раздел. Название может содержать цвета через `&` |
| `/sa removecategory <id>` | удалить раздел |
| `/sa stats [страница]` | счётчик проданного, по 10 предметов на странице |
| `/sa take <предмет> [кол-во\|all]` | забрать предметы из счётчика себе в инвентарь. Без количества выдаётся один стак |
| `/sa reload` | перезагрузить `config.yml` и `shop.yml` |

Имена предметов пишутся латиницей, как в игре: `DIAMOND`, `OAK_LOG`, `IRON_INGOT`. Работает автодополнение по Tab.

Примеры:

```
/sa addcategory tools DIAMOND_PICKAXE &bИнструменты
/sa add tools 15.5 IRON_PICKAXE
/sa add blocks 2            (предмет из руки)
/sa price blocks STONE 1.5
/sa take COBBLESTONE all
```

## Файлы плагина

Лежат в `plugins/SellShop/`:

| Файл | Что внутри |
|---|---|
| `config.yml` | префикс, заголовок меню, валюты, тексты сообщений |
| `shop.yml` | разделы, иконки, слоты, валюта раздела, предметы и цены |
| `stats.yml` | счётчик проданного (не редактируйте при работающем сервере) |
| `sales.log` | журнал продаж и выдач из счётчика |

Пример строки из `sales.log`:

```
[2026-11-13 13:30:12] SELL Steve sold 64x STONE for 64 (vault, category=blocks, mode=stack)
```

### Настройка раздела в `shop.yml`

```yaml
categories:
  blocks:
    title: "&aБлоки"      # название в меню
    icon: GRASS_BLOCK      # иконка в главном меню
    slot: 11               # слот в главном меню (-1 = автоматически)
    currency: vault        # vault или donate
    items:
      STONE: 1.0           # цена за 1 штуку
```

## Донатная валюта

По умолчанию все разделы платят обычными деньгами (`currency: vault`). Донатная валюта уже заложена, но выключена. Деньги выдаются командой от консоли.

1. В `config.yml` включите и настройте блок:

   ```yaml
   currencies:
     donate:
       enabled: true
       name: "донат-монет"
       command: "points give {player} {amount}"
   ```

   `{player}` и `{amount}` подставляются автоматически. Команду замените на ту, что выдаёт донат-валюту в вашем плагине.
2. В `shop.yml` у нужного раздела поставьте `currency: donate`.
3. Выполните `/sa reload`.

## Что важно знать

- Продаются только обычные предметы без имени, зачарований и других данных.
- Счётчик проданного сохраняется каждые 30 секунд и при выключении сервера.
- Все предметы, проданные игроками, попадают в счётчик, а не пропадают. Админ может забрать их командой `/sa take`.
